# Contributing

PlaceMatch is written and maintained by Pomerado's founders, Akshay and Alan.
Code contributions come only from them: we do not accept pull requests from
anyone else, and such pull requests are closed without review.

Issues are welcome. A useful report includes:

- the caller's address text, the candidate strings and the country code;
- what PlaceMatch answered and what you expected;
- for a wrong pick, why the two addresses are different places.

Please use made-up or public addresses in reports, never someone's private
address.
